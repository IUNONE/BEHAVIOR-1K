# J6：前驱动法兰 + 后被动惰轮

依据用户确认，J6 使用 XL330 和 FPX330-H101 配套的原厂背面惰轮。
本次更正的是两个正交电机槽的分工和装配表达，不新增受控自由度。

## 修正

旧模型把 `l7.obj` 的 X 轴电机槽作为 J6，把另一槽作为 J7，导致 J7 电机盒进入 `l6` 叉形支架区域。
该 X 轴槽的另一端邻接第二个电机，不适合 J6 所需的前后法兰支撑。

以原始 `l7.obj` 的毫米坐标表示：

| 项目 | 本次采用的位置 / 方向 |
|---|---|
| J6 壳体中心 | `(10, 20, 0)`；宽20、高34、深23；深度沿 Z |
| J6 转轴 | 通过 `(10, 12.5, 0)`，沿 Z，前后两侧均开放 |
| J6 驱动法兰 | 电机 +Z 端，对应原始 l6 的 +X 侧 |
| J6 背面惰轮 | 电机 -Z 端，对应原始 l6 的 -X 侧 |
| J7 壳体中心 | `(-11.627, 20, 0)`；深度沿 X |
| J7 输出安装面 | `(-26.127, 12.5, 0)`，朝 -X |

`l7` link 原点移到新的 J6 轴心，所以打印件 visual origin 变为 `(-10,-12.5,0) mm`。
J6 的 URDF 局部轴变为 Z，通过 joint origin 变换后仍与上一级叉架 X 轴同轴。
以用户提供的官方安装视频截图重新核对后，两台电机的轴心均位于原生 Y=12.5 mm 一端，壳体中心 Y=20 mm。因此壳体位于转轴的前臂侧。之前采用的 Y=27.5 mm 和 J7 额外 180° 朝向已撤销。J7 连接片固定相位改为 -90°，使连接臂与指托方向符合参考图。

装配参考初始姿态采用 JoyLo 原生 J6≈65°、J7≈-20°（另含上述固定相位），是单张截图投影的取整近似，不是编码器角度反求结果。网页另有“共同角归零（R1 对齐）”用于原先的零位对齐。
原始 OBJ 打印件没有修改。

## 被动转动如何表达

`j6_output_flange` 与 `j6_passive_idler` 是两个独立命名的零件，都用固定连接装到 `l6` 叉架上。
电机壳体和腕部支架属于 `l7`，通过 J6 相对叉架转动。因此背面惰轮相对电机壳体会被动转动，
但与拧紧在其上的叉架保持一致。没有把惰轮固定到电机壳体，也没有添加一个独立控制角度。
后端中心轴套作为 `l7` 的 `j6_idler_axle` 表示。

- 金色：前驱动法兰。
- 蓝色：后被动惰轮。
- 深灰色：电机壳体与中心轴套。

网页有“查看左腕 J6 前后法兰”和“隐藏打印件，看电机与法兰”控件。
源左臂修正后重新镜像生成右臂，双臂仍为 14 个独立关节。

## 尺寸依据与范围

[ROBOTIS X330 手册第14页](https://www.hannovermesse.de/apollo/hannover_messe_2025/obs/Binary/A1424108/_DXL__EN_ver2506%28%29_.pdf)
的尺寸图给出壳体深度 23 mm、前法兰外伸 3 mm、法兰外径16 mm、轴距壳体顶端9.5 mm。
[ROBOTIS 原厂 FPX330-H101 图纸](https://www.besttechnology.co.jp/modules/knowledge/gate.php/fpx330-h101.pdf?_noumb=&openfile=fpx330-h101.pdf&refer=BTX136+FPX330-H101+4pcs+Set&way=attach)
标注叉架净宽29 mm。[原厂安装说明](https://emanual.robotis.com/assets/images/dxl/x/x330/xl330_assembly_integrated.png)
展示背面 idler horn 和 idler cap 的连接方式。

当前后惰轮用直径16、厚3 mm 的环形包络表示，中央孔及轴盖为示意，**未取得惰轮单件精确 CAD**。
前后法兰中心在原生 l6 坐标 `(±13,76,0) mm`，总包络宽29 mm。
打印件 l6 内侧名义间距约28.8 mm，与原厂叉架净宽相差0.2 mm；此处保留原始打印件，
没有通过缩放网格来掩盖差异，实际装配需核对公差。

本次解决了错误电机槽引起的明显电机盒干涉。已有打印件之间的名义配合、全部角度组合的碰撞、
真实螺钉/惰轮尺寸仍未全部验证，不能据此直接进行制造或硬件运动控制。

## 回归检查

- J6 转轴与前、后两法兰共轴。
- 前后法兰均不被相邻 J7 电机盒挡住。
- 惰轮相对叉架固定、相对电机壳体随 J6 被动转动。
- 左右镜像关系与七对七 R1 Pro 映射保持正确。
- 不增加受控自由度。

## 2026-09-24 腕部安装方向修正（以本节为准）

按用户确认，以查看器零位时的 J6 中心为支点，绕身体前后 X 轴旋转 180°。
修改源 URDF 的 joint_6 固定安装旋转，紫色 l7 支架、两台腕部电机和下游手柄整体随动。
左臂源模型重新镜像生成右臂与双臂模型；重新运行 build_dual_joylo.py 会保留此修正。
J6 的安装中心、滑块初始数值保持原值。此前“壳体朝前臂侧”的安装描述已被本次修正替代。
这是模型安装变换，不是电机编码器标定；腕部运动方向需要后续实测标定确认。

## 2026-09-24 J7 零位朝向修正

在上述腕部安装修正基础上，按用户确认，将 J7 的固定安装旋转沿自身输出轴追加 180°。
手柄支架及 Joy-Con 随动，紫色支架与电机壳体不随本次修正旋转。
查看器 J7=0° 对应新的手柄朝向，滑块范围不变；源模型、左右臂与双臂模型同步更新。
该模型零位修正不修改实体电机的标定配置。
